In this nifty-but-gritty space, you’ll find our Software Engineering (SE) project, where ideas are built, bugs are battled, and progress is made...sometimes heroically, sometimes… minimally. We are Bare 

Rules:

1. All work must be done on a feature branch
2. Pull Requests are required
3. Always pull from main before starting new work

This project focuses on building a dedicated online space for gamers to connect within their local communities. The aim is to support knowledge sharing, skill development, and meaningful interaction among players beyond online gameplay. 
To address this, we plan to develop a website that enables users to:

* Connect with other gamers in their local community
* Share skills, strategies, and personal gaming experiences
* Create and access game guides and learning resources
* Organise local tournaments and community competitions

The platform aims to strengthen local gaming communities by providing a central hub for communication, collaboration, and shared learning.
