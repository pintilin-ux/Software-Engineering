Our project will building a online space for gamers to connect within their local communities. The aim is to share knowledge, skill improvement, and a friendly enviroment. 
We plan to develop a website that enables users to:

* Connect with other gamers in their local community
* Share skills, strategies, and personal gaming experiences
* Create and access game guides
* Organise local tournaments and community competitions

The website aims to build a stronger local gaming community by providing a central hub for communication, collaboration, and shared learning.**
